# موقع تعريفي لمصمم جرافيك

موقع بالعربي والإنجليزي، بنفس أسلوب وحركات studiomodular.be، ويعمل على الكمبيوتر والآيباد والجوال.

المشروع فيه **نسختان بنفس التصميم والحركات**. اختر واحدة فقط:

| | `static/` (HTML/CSS/JS) | `nextjs/` (Next.js + React) |
|---|---|---|
| مناسبة لـ | البداية السريعة، أي استضافة | مشروع أكبر، Vercel، تحسين محركات البحث |
| التشغيل | افتح `index.html` | `npm install` ثم `npm run dev` |
| المحتوى | `static/assets/js/content.js` | `nextjs/content/site.js` |
| التصميم | `static/assets/css/style.css` | `nextjs/app/style.css` |
| الحركات | `static/assets/js/motion.js` | `nextjs/lib/motion.js` |
| الصور | `static/assets/img/` | `nextjs/public/assets/img/` |

> ملفات التصميم والحركات والمحتوى **متطابقة** بين النسختين. إذا عدّلت واحدة ولاحقاً قررت تنتقل للثانية، انسخ الملف كما هو.

---

## 1) تعديل المحتوى

كل النصوص والصور في **ملف واحد** (`content.js` أو `site.js`). كل نص مكتوب باللغتين:

```js
title: { ar: "نخلة كوفي", en: "Nakhla Coffee" },
```

- **اسمك ومعلوماتك:** قسم `brand` (الاسم، الكلمتان الكبيرتان في الهيرو، البريد، الجوال، السوشيال).
- **مشروع جديد:** انسخ أي عنصر داخل `cases` وغيّر `slug` (اسم بالإنجليزي بدون مسافات، يظهر في الرابط).
  - `services` قائمة بأسماء الخدمات (`strategy`, `identity`, `print`, `web`, `social`) وتُستخدم في الفلترة.
  - `video`: ضع مسار ملف mp4 ليظهر فيديو بدل صورة الغلاف.
  - `gallery`: صور صفحة المشروع، و`size` إما `full` (عرض كامل) أو `half` (نصف).
  - `featured: true` يعني أن المشروع يظهر في الصفحة الرئيسية.
- **الخدمات:** قسم `services`، ولكل خدمة لونها (`bg` للخلفية و`fg` للنص).
- ⚠️ **آراء العملاء والشعارات الحالية وهمية للتجربة.** استبدلها بآراء وشعارات حقيقية قبل النشر.

## 2) الصور

الصور الحالية رسومات مؤقتة (SVG). ضع صورك في مجلد الصور ثم غيّر اسم الملف في ملف المحتوى. أي صيغة تعمل: `jpg`, `png`, `webp`, `avif`, `svg`.

المقاسات المقترحة:

| الصورة | النسبة |
|---|---|
| غلاف المشروع | 4:5 (مثلاً 1200×1500) |
| صور المعرض full | 16:9 (مثلاً 2000×1125) |
| صور المعرض half | 4:5 |
| صورتك الشخصية | 4:5 |
| شعارات العملاء | SVG أو PNG بخلفية شفافة |

لا تحتاج تقص الصور بدقة، فكل صورة تملأ إطارها تلقائياً (`object-fit: cover`). لكن **اضغط الصور** قبل رفعها (مثلاً عبر squoosh.app) حتى يبقى الموقع سريعاً.

## 3) الألوان والخط

في أول ملف التصميم (`style.css`) قسم `:root`:

```css
--c-bg:#f5f0e8;       /* الخلفية */
--c-primary:#26235c;  /* اللون الأساسي: القسم الملون والفوتر والأزرار */
--c-accent:#d4f36b;   /* لون التمييز: زر القائمة والدوائر */
```

الخط **Readex Pro** (مجاني، يدعم العربي والإنجليزي) ومستضاف داخل المشروع في مجلد `fonts`.

## 4) نموذج التواصل

افتراضياً يفتح النموذج برنامج البريد عند الزائر. لاستقبال الرسائل مباشرة:

1. سجّل في [formspree.io](https://formspree.io) (مجاني) وأنشئ نموذجاً.
2. انسخ الرابط (مثل `https://formspree.io/f/abcdwxyz`) وضعه في `brand.formEndpoint`.

## 5) اللغة الافتراضية

- **static:** في `assets/js/lang.js` غيّر `DEFAULT_LANG`.
- **nextjs:** في `next.config.mjs` غيّر `destination: "/ar"` إلى `"/en"`.

## 6) الحركات

كل الحركات في `motion.js` ومشروحة في أعلاه. كل حركة مرتبطة بخاصية في الـ HTML (مثل `data-reveal` لكشف النص)، فتقدر تضيفها لأي عنصر أو تحذفها.

المكتبات المستخدمة: **GSAP** (مع ScrollTrigger وSplitText) و**Swiper** لسلايدر الآراء. كلها مجانية للاستخدام التجاري.

الموقع يحترم إعداد "تقليل الحركة" في جهاز الزائر، ويوقف الحركات إذا كان مفعّلاً.

---

## النشر

**static:** ارفع محتوى مجلد `static` كما هو إلى أي استضافة: Netlify (اسحب المجلد وأفلته في netlify.com/drop)، أو GitHub Pages، أو Cloudflare Pages، أو استضافتك العادية.

**nextjs:** ارفع المشروع على GitHub ثم اربطه بـ [Vercel](https://vercel.com). يُبنى وينشر تلقائياً بدون أي إعداد.
